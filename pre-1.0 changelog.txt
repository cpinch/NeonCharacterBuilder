v0.7 - Full Features
	All options for selection in classes and species are now supported
	Reworked the code internals. Now, all things (feats, features, species, etc) that modify the character's set of values share a common class that handles getting/setting these features and takes care of getting all of these changes for the feature and its children recursively. So instead of having to write code for a class to check its class features and each of those features to check its selectable options and each of those to check its data etc it's all automatically handled. This is a huge improvement to the old spagetti and makes the code far simpler and more effective.
	Made some minor UI improvements like standardizing display of all character changes and making ability scores easier to enter.
